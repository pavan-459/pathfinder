# Problems

One file per solved problem, named `lc<number>-<short-name>.js`, e.g. `lc1574-min-remove-to-sort.js`.

Copy [`_template.js`](./_template.js), fill in the header **before** you write the code, then solve. The header matters more than the code: it's what you'll say out loud in the interview.

Commit after every problem:

```bash
git add problems/lc1574-min-remove-to-sort.js roadmap.md
git commit -m "LC 1574: two pointers, O(n) / O(1)"
git push
```

Your GitHub contribution graph then shows the streak.
